# Telegram Bot для предложений треков

Телеграм бот для сбора предложений музыкальных треков с автоматической интеграцией в Google Sheets. Поддерживает тысячи одновременных запросов.

## Особенности

- ✅ Сбор данных через интерактивную форму (7 вопросов)
- ✅ Автоматическое сохранение в Google Sheets
- ✅ Поддержка тысяч одновременных пользователей
- ✅ Возможность отмены заявки в любой момент
- ✅ Полная русскоязычная локализация
- ✅ Сводка ответов после отправки

## Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd rodzvuk-tg-bot
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта:
```bash
# Telegram Bot Configuration
BOT_TOKEN=your_telegram_bot_token_here

# Google Sheets Configuration
GOOGLE_SHEET_ID=your_google_sheet_id_here
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nYour_private_key_here\n-----END PRIVATE KEY-----\n"
GOOGLE_CLIENT_EMAIL=your_service_account_email@project.iam.gserviceaccount.com
```

## Настройка Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/BotFather):
   - Отправьте `/newbot`
   - Выберите имя и username для бота
   - Получите токен бота

2. Скопируйте токен в переменную `BOT_TOKEN` в файле `.env`

## Настройка Google Sheets

### Шаг 1: Создайте Google Sheets таблицу

1. Перейдите в [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Скопируйте ID таблицы из URL (между `/d/` и `/edit`)
   - Пример: `https://docs.google.com/spreadsheets/d/1ABC123DEF456/edit`
   - ID: `1ABC123DEF456`

### Шаг 2: Настройте Google Service Account

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com)
2. Создайте новый проект или выберите существующий
3. Включите Google Sheets API:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и включите его

4. Создайте Service Account:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "Service Account"
   - Введите имя и описание
   - Нажмите "Create and Continue"
   - Пропустите настройки ролей (нажмите "Continue" → "Done")

5. Создайте ключ для Service Account:
   - Нажмите на созданный Service Account
   - Перейдите во вкладку "Keys"
   - Нажмите "Add Key" → "Create New Key"
   - Выберите "JSON" и нажмите "Create"
   - Скачайте JSON файл

6. Из скачанного JSON файла скопируйте:
   - `private_key` → в `GOOGLE_PRIVATE_KEY`
   - `client_email` → в `GOOGLE_CLIENT_EMAIL`

### Шаг 3: Предоставьте доступ к таблице

1. Откройте вашу Google Sheets таблицу
2. Нажмите "Share" (Поделиться)
3. Добавьте email из `client_email` с правами "Editor"
4. Нажмите "Send"

## Использование

### Команды бота

- `/start` - Приветственное сообщение
- `/suggest` - Начать предложение трека
- `/cancel` - Отменить текущую заявку
- `/help` - Показать справку

### Процесс предложения трека

1. Пользователь отправляет `/suggest`
2. Бот задает 7 вопросов по порядку:
   - Как тебя зовут?
   - Исполнитель и название трека
   - Ссылка на трек
   - Язык трека (русский/английский)
   - Жанр музыки
   - Почему рекомендуешь этот трек?
   - Твой контакт (опционально)

3. После ответа на все вопросы данные автоматически сохраняются в Google Sheets
4. Пользователь получает подтверждение с сводкой ответов

### Структура данных в Google Sheets

Колонки в таблице:
- **Дата** - Дата и время подачи заявки
- **Имя** - Имя пользователя
- **Исполнитель и трек** - Название трека
- **Ссылка** - Ссылка на трек
- **Язык** - Язык трека
- **Жанр** - Жанр музыки
- **Причина рекомендации** - Описание от пользователя
- **Контакт** - Контактная информация (опционально)
- **User ID** - Telegram ID пользователя
- **Username** - Telegram username

## Конфигурация

### Изменение вопросов

Отредактируйте массив `QUESTIONS` в файле `config.js`:

```javascript
QUESTIONS: [
  'Ваш новый вопрос 1',
  'Ваш новый вопрос 2',
  // ... и так далее
]
```

### Добавление вопросов

1. Добавьте новый вопрос в массив `QUESTIONS`
2. Обновите `getQuestionKey()` метод в `bot.js`
3. Добавьте новую колонку в Google Sheets
4. Обновите `addSubmission()` метод в `sheets.js`

## Деплой

### Heroku

1. Создайте приложение на Heroku
2. Добавьте переменные окружения в Settings → Config Vars
3. Подключите GitHub репозиторий

1. Установите Node.js на сервер
2. Клонируйте репозиторий
3. Установите зависимости
4. Настройте PM2 для автозапуска:
```bash
npm install -g pm2
pm2 start bot.js --name "rodzvuk-bot"
pm2 save
pm2 startup
```

## Масштабирование

Бот использует Map для хранения состояний пользователей в памяти, что позволяет обрабатывать тысячи одновременных запросов. Для еще большей нагрузки можно:

1. Использовать Redis для хранения состояний
2. Разделить бота на несколько инстансов
3. Использовать webhook вместо polling

## Устранение неполадок

### Ошибки Google Sheets API

- Проверьте правильность `GOOGLE_SHEET_ID`
- Убедитесь, что Service Account имеет доступ к таблице
- Проверьте формат `GOOGLE_PRIVATE_KEY` (должен содержать `\n`)

### Ошибки Telegram Bot

- Проверьте корректность `BOT_TOKEN`
- Убедитесь, что бот не запущен в другом месте
- Проверьте сетевое подключение

### Логи

Бот выводит подробные логи в консоль:
- Успешные операции
- Ошибки инициализации
- Ошибки сохранения данных
